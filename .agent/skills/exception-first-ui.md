# Exception-First Design

Normal operational cases need minimal visual clutter, while exceptions, delays, and shortages must immediately grab attention. This is critical for Stores and Production screens.

## Standard Exception Markers
- `⚠ Material Pending`
- `⚠ Partial Issue`
- `⚠ Additional Requirement`
- `⚠ Excess Material`
- `⚠ Material Returned`
- `⚠ Discrepancy / Rejection`

## Normal vs. Exception Comparison
```text
Normal Row:
EN31   Ø110×35   Required: 2   Issued: 2   ✓ Complete

Exception Row:
MS     Ø150×15   Required: 4   Issued: 2   ⚠ PENDING 2
```

## Highlighted Attention Cards
```text
ADDITIONAL MATERIAL REQUEST — SC-003
```
