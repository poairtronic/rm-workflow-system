# RMRIT User Stories

## 1. Design Engineer

- **US-1.1**: As a Design Engineer, I want to create and submit an RM list for an SC by entering material grades, profiles, sizes, and quantities directly to Stores so that stock can be allocated without approval bottlenecks.
- **US-1.2**: As a Design Engineer, I want to view historical snapshots of my revisions so that all dimensional changes are traceable.

## 2. Stores Manager

- **US-2.1**: As a Stores Manager, I want to view submitted RM requests directly from Design and check inventory availability.
- **US-2.2**: As a Stores Manager, I want to issue materials (full or partial) and record heat/batch numbers for traceability.
- **US-2.3**: As a Stores Manager, I want to acknowledge physical returned materials from Production.

## 3. Production Operator

- **US-3.1**: As a Production Operator, I want to confirm receipt of issued raw materials before starting machining.
- **US-3.2**: As a Production Operator, I want to log consumed quantities, return unused materials, and request additional material with explicit defect/error reasons.
- **US-3.3**: As a Production Operator, I want to mark production complete for an individual SC with closing notes.

## 4. Senior Manager & General Manager (Monitoring & Analytics)

- **US-4.1**: As a Senior / General Manager, I want real-time dashboard telemetry and immediate alerts when shortages or scrap requests occur on the shop floor.
- **US-4.2**: As a Senior / General Manager, I want to audit complete material reconciliation ledgers across all completed SCs without being an approval gatekeeper.
