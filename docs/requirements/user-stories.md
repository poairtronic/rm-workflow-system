# RMRIT User Stories

## 1. Design Engineer
- **US-1.1**: As a Design Engineer, I want to create an RM list for an SC by entering material grades, profiles, sizes, and quantities so that Stores can prepare raw materials.
- **US-1.2**: As a Design Engineer, I want to view rejection notes from the Senior Manager so that I can revise dimensions and re-submit.

## 2. Senior Design Manager
- **US-2.1**: As a Senior Design Manager, I want to review submitted RM lists, approve them, or edit dimensions with revision remarks so that verified requests advance to Stores.
- **US-2.2**: As a Senior Design Manager, I want to receive immediate alerts when shortages or additional material requests occur on the shop floor.

## 3. Stores Manager
- **US-3.1**: As a Stores Manager, I want to view verified RM requests and check physical stock availability.
- **US-3.2**: As a Stores Manager, I want to issue materials (full or partial) and record heat/batch numbers.
- **US-3.3**: As a Stores Manager, I want to acknowledge physical returned materials from Production.

## 4. Production Operator
- **US-4.1**: As a Production Operator, I want to confirm receipt of issued raw materials before starting machining.
- **US-4.2**: As a Production Operator, I want to log consumed quantities, return unused materials, or request additional material with explicit defect/error reasons.
- **US-4.3**: As a Production Operator, I want to mark production complete for an individual SC.
