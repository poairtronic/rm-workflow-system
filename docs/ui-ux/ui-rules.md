# UI/UX Rules & The Real Employee Test

## The 10 UI/UX Skills

1. `human-centered-workflow-ui`: Center screens around the user's immediate job-to-be-done.
2. `information-hierarchy`: Lead with SC number, current status, and required action.
3. `manufacturing-domain-ui`: Speak strict manufacturing language (PO, SC, Grade, Size, Qty, Issue, Return).
4. `workflow-state-ui`: Show state progression trails and dual-encoded badges (symbol + text).
5. `realistic-data-design`: Never use placeholder text; use real industrial grades and dimensions.
6. `progressive-disclosure-ui`: Disclose details in 3 tiers (Summary $\rightarrow$ Movement $\rightarrow$ Full Log).
7. `audit-trail-ui`: Render clear, chronological material movement histories.
8. `business-form-ux`: Build sequential, compact input dialogs rather than 30-field forms.
9. `exception-first-ui`: Visually elevate shortages, pending items, and additional requests.
10. `anti-ai-ui`: Avoid purple gradients, glassmorphism, and excessive decorations.

## The Real Employee Test

An operator or manager looking at a screen must be able to answer:

- Which SC is active?
- Which materials are required, available, and pending?
- What action is required from me right now?
