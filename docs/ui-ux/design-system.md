# RMRIT UI Design System Specification

## Visual Hierarchy

$$\text{SC Identifier} \longrightarrow \text{Workflow Status} \longrightarrow \text{Primary Action} \longrightarrow \text{Material Grid} \longrightarrow \text{Audit Log}$$

## Color Tokens & Semantics

- **Background**: `#0F172A` (Dark slate)
- **Cards / Containers**: `#1E293B`
- **Border**: `#334155`
- **Status Badges**:
  - `Draft`: `#64748B`
  - `Pending`: `#F59E0B`
  - `Active / Issued`: `#3B82F6`
  - `Completed`: `#10B981`
  - `Rejected / Alert`: `#EF4444`

## Typography

- **Headings & Body**: `Inter`, system-ui
- **Tabular & Codes (SC, PO, Sizes)**: `JetBrains Mono`, monospace
