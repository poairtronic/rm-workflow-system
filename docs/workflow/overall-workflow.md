# RMRIT Overall Workflow

```text
Customer Order
      ↓
PO Context Entered (e.g. PO-100)
      ↓
SC Selected / Created (e.g. SC-003)
      ↓
Design Prepares RM List
      ↓
Senior Design Manager Verification (Approve / Edit / Reject)
      ↓
Stores Checks Physical Stock Availability
      ↓
Stores Issues Material (Full / Partial)
      ↓
Production Confirms Receipt
      ↓
Production Consumes / Returns Material
      ↓
Additional Material Request (If Needed with Reason)
      ↓
Production Complete → SC CLOSED
```
